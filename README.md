## v6.5 확인 사항
모의면접 질문 직접선택 화면의 상위 목록에 다음 3개 항목이 바로 표시됩니다.
1. 2027 예상문제
2. 황우원 교수님 예상문제
3. 곽상경 교수님 예상문제

상위 항목 클릭 → 해당 질문 목록 표시 → 1~5문항 체크 → 선택한 질문으로 연습 순서로 사용합니다.
