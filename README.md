# v6.3 출처별 질문선택판

모의면접의 직접 선택 영역을 출처별로 재구성했습니다.

- 📌 2027 예상문제 전체: 황우원 교수님 + 곽상경 교수님 자료의 2027 대비 문항 전체
- 🟦 황우원 교수님 예상문제: 황우원 교수님 제공 자료 수록 문항
- 🟪 곽상경 교수님 예상문제: 곽상경 교수님 자료 수록 문항
- 📚 역대 기출문제
- 📝 기존 예상문제

각 항목을 클릭하면 하위 문제가 펼쳐지고 최대 5문항까지 직접 선택해 연습할 수 있습니다.
같은 문항이 '2027 예상문제 전체'와 교수님별 목록에 동시에 보일 수 있지만, 선택은 문항 ID 기준으로 중복되지 않습니다.
